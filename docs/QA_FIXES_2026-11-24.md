# Talentfolio AI — UX / Workflow Fixes (2026-11-24)

## Changes implemented
1. **Portfolio:** separate work experience from education in all nine portfolio template families; remove long-bio clipping in Crimson and mobile variants.
2. **Projects:** display an interactive preview of the linked website when no project images are uploaded; display user's gallery photos (with lightbox) when supplied. Each website card offers an external link when iframe embedding is blocked by the website's CSP/X-Frame-Options.
3. **Work images:** replace browser-native upload input with a prominent file-selection and drag-and-drop area and thumbnail previews; existing JPG/PNG/WebP 5MB and 12-images/project limits remain. Work gallery objects are public by direct URL — do not upload confidential data.
4. **Skills:** free-text Add/Update/Delete, suitable for skills beyond the five fixed categories. Saves use user-scoped Supabase RLS and confirm the returned record.
5. **Resume Studio:** Executive, Modern and Creative templates, profile picture, optional project-cover images and separate Education and Work Experience, printable A4 PDF through browser.
6. **Dark mode:** toggle on the workspace header; stored in browser localStorage for all app routes.
7. **Prompt Generator:** separate project/skill/education/experience professional prompts, Malay or English, one-click copy, integrated into workspace navigation. Does not automatically call an AI provider.
8. **AI analysis:** a server-only Next.js API endpoint validates the signed-in Supabase user, fetches user-owned skill and career data, and calls OpenAI Responses API **only if `OPENAI_API_KEY` has been configured**. User consent checkbox required before model call. Never put provider secrets in `NEXT_PUBLIC_*`. The AI provider's API may charge per request; users must configure billing and spend control themselves.

## Manual live testing still required
- Two accounts: check other users cannot modify/read private records; verify RLS.
- Project: enter public website URL, view preview, try an external website which blocks iframe, confirm external button.
- Project gallery: select 1-3 images, upload, caption, cover, reorder, delete, republish and view the public page.
- Skills: add uncommon free-text skill, update name and rating, delete, refresh page and confirm persistence.
- Resume: compare all three styles in browser print preview; check profile photo and project cover as downloaded A4 PDF. With no uploaded avatar or project photo, a fallback symbol is expected.
- Dark mode: toggle, navigate dashboard/prompt page, reload, verify persistence.
- AI: once model secret and usage limits have been configured, test real auth-protected analysis. The default deployment has no AI provider key, so AI analysis currently displays a configuration message instead of claiming a fictitious AI result.
- Mobile visual QA: Chrome, Safari, Firefox, long biographies and narrow screens.
- Check security advisor: enable leaked-password protection in Supabase when available.
- **Commercial hosting:** Vercel Hobby is non-commercial. Move to a commercially appropriate plan before a paid SaaS release.

## AI key setup
In Vercel Project > Settings > Environment Variables, create a **server-only secret** `OPENAI_API_KEY` and, optionally, `OPENAI_MODEL=gpt-5-mini`. Set targets appropriately and redeploy. Do not paste keys into a public chat or commit them to GitHub. Consider provider privacy/consent and a strict usage quota before a commercial launch.

## Change tracking
The existing database schema and gallery RLS policies were kept; no new live migrations needed for these UI improvements.
